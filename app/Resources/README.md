# Application icon

The app shows itself as **Files**. Its mark is a filled tile that is itself a folder, edge to edge: a navy back with a tab at the top left, a white sheet peeking out, and a bright front flap. It is original artwork, not Apple's Finder mark.

The artwork is drawn full bleed and clipped to the macOS icon grid: an 824 px rounded square with 100 px margins. An icon that does not fill that shape is put on a gray plate in the Dock by recent macOS releases, which is what happened to a folder-shaped silhouette.

- `AppIcon-artwork.png`: drawn by `app/tools/draw-icon-artwork.swift` (run `swift tools/draw-icon-artwork.swift Resources/AppIcon-artwork.png`, then `tools/make-icon.sh`).
- `AppIcon.png`: the 1024px master, the artwork clipped to the icon grid by `app/tools/render-icon.swift`.
- `icon-prompt.txt`: the generation prompt for the previous, Tursora-era mark, kept for history.
- `AppIcon.icns`: 16–1024px icon family, generated by `app/tools/make-icon.sh`.
- `app/tools/make-app.sh`: embeds the family and registers `CFBundleIconFile`.

A legacy ICNS shows its own alpha silhouette, so the rounded tile is baked into the PNG. See [Apple's app icon guidelines](https://developer.apple.com/design/human-interface-guidelines/app-icons). The smoke test checks dimensions, a transparent border, transparent corner regions, an opaque interior, and icon-family sizes. Actual Dock appearance also requires visual inspection after packaging.

The spacing edit was checked in the packaged 0.1.0 (4) About panel using computer use: the mark sits comfortably inside the system-rounded icon with one background. All 618 smoke checks passed three consecutive runs; the packaged ICNS matches the source and the app signature verifies.
