# Application icon

The app shows itself as **Files**. Its mark is one large blue folder that is the icon's whole silhouette, with no tile behind it: a darker back with a tab, a white sheet peeking out, a bright front flap and a faint divider hinting at the two panes. It is original artwork, not Apple's Finder mark.

The folder spans about 86% of the canvas width (72 px margins) and carries its own soft drop shadow; everything around it is transparent.

- `AppIcon-artwork.png`: drawn by `app/tools/draw-icon-artwork.swift` (run `swift tools/draw-icon-artwork.swift Resources/AppIcon-artwork.png`, then `tools/make-icon.sh`).
- `AppIcon.png`: the 1024px master, the artwork copied unclipped by `app/tools/render-icon.swift`.
- `icon-prompt.txt`: the generation prompt for the previous, Tursora-era mark, kept for history.
- `AppIcon.icns`: 16–1024px icon family, generated by `app/tools/make-icon.sh`.
- `app/tools/make-app.sh`: embeds the family and registers `CFBundleIconFile`.

A legacy ICNS shows its own alpha silhouette, so the folder shape is what the Dock and Finder draw. See [Apple's app icon guidelines](https://developer.apple.com/design/human-interface-guidelines/app-icons). The smoke test checks dimensions, a transparent border, corner regions free of opaque fill (the drop shadow may reach them faintly), an opaque interior, and icon-family sizes. Actual Dock appearance also requires visual inspection after packaging.

The spacing edit was checked in the packaged 0.1.0 (4) About panel using computer use: the mark sits comfortably inside the system-rounded icon with one background. All 618 smoke checks passed three consecutive runs; the packaged ICNS matches the source and the app signature verifies.
